# Abstractive Text Summarization using Seq2Seq LSTM and Attention Mechanism

## Overview
This project implements an Abstractive Text Summarization model using Seq2Seq architecture with LSTM and Attention Mechanism.

## Technologies Used
- Python
- TensorFlow
- Keras
- LSTM
- Seq2Seq
- Attention Mechanism

## Features
- Generates summaries from long text
- Encoder-Decoder architecture
- Attention-based sequence learning
- NLP based text processing
